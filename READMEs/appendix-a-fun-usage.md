# 附录 A：`fun` 关键字的三种用法

| 形式 | 章节 | 示例 | 说明 |
|------|------|------|------|
| 顶层/方法声明 | §5.1 | `fun add(a: int, b: int) -> int { ... }` | 定义具名函数或方法 |
| 闭包字面量 | §5.3 | `let f = fun(x: int) -> int { return x * 2 }` | 作为表达式，创建匿名函数值 |
| 函数类型注解 | §3.2 | `fun(int) -> int` | 用于变量注解、参数类型、返回类型 |
