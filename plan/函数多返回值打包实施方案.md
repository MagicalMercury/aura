## 1. 目标

`fun divmod(a: int, b: int) -> (int, int)` + `return a / b, a % b` + `let q, r = divmod(7, 3)`。

**设计决策（方案 B' 修正版：元组 = 匿名 record 语法糖，canonicalName 延迟到 CodeGen 合成）**：元组在 Sema 层表示为 `RecordSemType`（位置字段名 `_0`/`_1`/... + `bool isTuple = true`，**canonicalName 留空**）；C++ 类型名 `aura_rt::TupleN<...>*` 由 `mapSemType`/`mapType` 对 `isTuple` 标志**现场递归合成**。相比原 plan（Sema 合成 canonicalName）的关键修正：**`resolveType` 位于 Sema 层无法调用 CodeGen 的 `mapSemType`**，若在 Sema 复制一套"SemType→C++ 名"映射会产生双份漂移；延迟合成让元组类型名永远与既有类型映射一致。

```cpp
// runtime/builtin/tuple.h
#ifndef AURA_RT_BUILTIN_TUPLE_H
#define AURA_RT_BUILTIN_TUPLE_H

#include "../types.h"
#include "../gc/gc.h"
#include <cstddef>
#include <tuple>
#include <type_traits>
#include <utility>

// offsetof 用于继承 GcObject 的非标准布局类（项目先例：types.cpp / string.cpp）
#pragma GCC diagnostic push
#pragma GCC diagnostic ignored "-Winvalid-offsetof"

#define AURA_RT_CAT(a, b) AURA_RT_CAT_I(a, b)
#define AURA_RT_CAT_I(a, b) a##b

namespace aura_rt {

// 视图检测 trait：复制自 variant.h L29-38（其内部定义非共享，此处独立一份并注明来源）
template <typename T, typename = void>
struct is_iface_view : std::false_type {};
template <typename T>
struct is_iface_view<T, std::void_t<
    decltype(std::declval<T&>().self),
    std::enable_if_t<std::is_convertible_v<
        decltype(std::declval<T&>().self), GcObject*>>
>> : std::true_type {};
template <typename T>
inline constexpr bool is_iface_view_v = is_iface_view<T>::value;

// ---- 每字段偏移收集（desc 需 const size_t* 且生命周期全局，用静态局部数组）----
// 指针字段 → offsetof(TupleT, _I)；视图字段 → offsetof(TupleT, _I) + offsetof(T, self)；
// 值字段 → 0（由 count 过滤不参与扫描）
template <typename TupleT, typename TupleTypes, size_t... I>
static const size_t* tupleOffsetsImpl(std::index_sequence<I...>) {
    static const size_t offs[] = {
        ([]() -> size_t {
             using T = std::tuple_element_t<I, TupleTypes>;
             if constexpr (std::is_pointer_v<T>)
                 return offsetof(TupleT, AURA_RT_CAT(_, I));
             else if constexpr (is_iface_view_v<T>)
                 return offsetof(TupleT, AURA_RT_CAT(_, I)) + offsetof(T, self);
             else
                 return 0;
         }(), ...)
    };
    return offs;
}

// 统一 desc 构造：count = 指针/视图字段数；offs = 收集数组
template <typename TupleT, typename... Ts>
static const TypeDescriptor makeTupleDesc() {
    using TupleTypes = std::tuple<Ts...>;
    constexpr size_t count =
        (size_t((std::is_pointer_v<Ts> || is_iface_view_v<Ts>)) + ...);
    static const size_t* offs = tupleOffsetsImpl<TupleT, TupleTypes>(
        std::index_sequence_for<Ts...>{});
    static const TypeDescriptor d = { sizeof(TupleT), count, offs, 0, nullptr, nullptr };
    return d;
}

// ---- Tuple2~Tuple8：宏批量生成具名模板（T0 _0; T1 _1; ...）----
// Tuple1 不生成：单元素 `(T)` 在 TypeParser 保持"括号分组"（§4 边界表），不构成元组
#define AURA_RT_DEFINE_TUPLE(N, FIELDS, PARAMS, ARGS)                                \
    template <PARAMS>                                                                \
    struct AURA_RT_CAT(Tuple, N) : GcObject {                                        \
        FIELDS                                                                       \
        static const TypeDescriptor _desc;                                           \
    };                                                                               \
    template <PARAMS>                                                                \
    const TypeDescriptor AURA_RT_CAT(Tuple, N)<ARGS>::_desc =                        \
        makeTupleDesc<AURA_RT_CAT(Tuple, N)<ARGS>, ARGS>();

AURA_RT_DEFINE_TUPLE(2, T0 _0; T1 _1;,
    typename T0, typename T1, T0, T1)
// …… 同型展开至 Tuple8（Tuple3~Tuple7 省略书写，实施时补齐）

#undef AURA_RT_DEFINE_TUPLE
#pragma GCC diagnostic pop

} // namespace aura_rt
#endif // AURA_RT_BUILTIN_TUPLE_H
```

## 4. 边界条件处理

| 边界 | 现状 | 计划 | 测试 |
|:---|:---|:---|:---|
| `(T)` 单元素 | 括号分组返回 T | 保持分组，不构成元组 | `-> (int)` |
| `()` 空元组 | 报 "expected type in parentheses" | 保留报错 | `-> ()` |
| 解构数量不匹配 | 无 | checkLetDecl 报错 | `let a = divmod(7,3)` / `let a,b,c = divmod(7,3)` |
| 解构目标非 record | 无 | checkLetDecl 报错 | `let a, b = 7` |

| 嵌套元组 | 字段类型可为 record | 自然支持（TupleN* 指针字段） | `let p, x = outer()` 后 `let p1, p2 = p` |

## 7. 风险与缓解

| 风险 | 缓解 |
|:---|:---|
| TupleN `_desc` 偏移错误（非标准布局 offsetof UB） | 配 pragma（types.cpp/string.cpp 先例）；单元测试验证含字符串字段的元组在 gc_force 后字段值正确 |
| `equals` 加 isTuple 影响既有比较 | 仅元组 isTuple=true 受影响；既有 record 全 false 不变；回归覆盖 type 别名/record 比较 |
| 解构 `_tup_N` 临时变量跨 GC | `_t_raw` + `_tup_N` 连续语句，无中间分配点（与 L440-444 同模式） |
| mapType/mapSemType 两处元组合成逻辑漂移 | 两处均"递归映射元素"，结构一致；回归用例同时覆盖标注/推断两条路径 |
| 表达式层元组字面量不支持导致嵌套构造受限 | 嵌套元组通过函数调用返回（`return inner(), 3`）；表达式字面量记为已知限制 |
| 解构目标含 Optional 字段（`(Optional<int>, int)`） | 字段类型 `aura_rt::Optional<int>*` 是指针 → GcRootHandle 分支 ✅ |
| 元组字段数与 TupleN 上限（8） | resolveType 处对 elementTypes.size()>8 报错（canonicalName 合成处防御） |
