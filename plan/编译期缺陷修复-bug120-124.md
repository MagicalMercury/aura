## 4. Proposed Changes

### 4.1 bug-122（先做，最小改动）

**What**：`evalMetaCall` 在 callee 为 `MetaMemberExpr` 时：
1. 求值 `callee.base` 得到 `Value obj`；
2. 按方法调用分发（内建白名单 → record 用户方法 → 明确失败），复用抽出的 `callMethodOn`。

**Where**：
- `src/CompileTime/Evaluator.cpp:528-541`（新增 MetaMemberExpr 分支）；
- 抽 `Value Evaluator::callMethodOn(Value obj, const std::string& name, const std::vector<std::unique_ptr<ASTNode>>& args, Env& env, const ASTNode& at)`；
- **`callBuiltinMethod` 签名解耦**（`Evaluator.h:93-94`）：第 3 参由 `const MethodCallExpr&` 改为「`args` + `const ASTNode& at`」（C6 证据：实现只用 `call.args` 与 `fail(call,…)`）。

**Why**：AST 事实（C1）决定唯一落点是求值器分流；不采用 Parser 方案（破坏 C4 契约）。

**代码骨架**：
```cpp
// evalMetaCall 开头（Evaluator.cpp:529 之前）
if (auto* mm = dynamic_cast<const MetaMemberExpr*>(call.callee.get())) {
    Value obj = co_await evalExpr(*mm->base, env);        // 协程化后；S1 前为 evalExpr(...)
    return callMethodOn(std::move(obj), mm->member, call.args, env, call);
}
auto* r = dynamic_cast<const MetaValueRefExpr*>(call.callee.get());
if (!r) fail(call, "only '#fun' calls are supported in Phase 3");
```

### 4.2 bug-121（`===` 新符号 + 编译期 `==` 身份语义）

**前置裁定**：**是否引入 `===` 本身**见 §10-1；若主人选"拆案"，则本 plan 只做「`==` 身份化」，`===` 另立 feature。

**What**：
1. 新增 token `TokType::StrictEq`（`===`），登记 `tokTypeName`（B2）；
2. Lexer：`==` 分支先探第三个 `=`（B1）；
3. Parser：`parseEquality` 的 ops 加 `StrictEq`（B3）；
4. Sema：`inferBinaryExpr` 对 `op == "==="` 报 `'===' is compile-time only`；**CodeGen 双保险**：`ExprBinary.cpp:256` 兜底分支对 `===` 也 `fail`（B6/🟡-4）；
5. Value：新增 `std::uint64_t ident = 0;`；**只给 list / Optional 的 5 个构造点赋值**（`Evaluator.cpp:185`、`:858`、`:866`、`:903`、`:911`；`append` 返回新容器赋新 id）。**record(`:194`) / Enum(`:224`) 不加**（它们走内容/变体比较，`ident` 无消费者）；
6. `evalBinary` 语义分流（`Evaluator.cpp:373-390`）：
   - `==`/`!=`：标量值比较；list/Optional **身份**（`ident != 0 && l.ident == r.ident`）；record 内容；string 值；
   - `===`：`l.equals(r)`。

**Where**：`TokType.h:31`、`TokType.cpp:56`、`Lexer.cpp:75-78`、`ExprParser.cpp:133-136`、`ExprInfer.cpp:591-602`、`ExprBinary.cpp:256-261`、`Value.h:34-45`、`Evaluator.cpp:373-390` + 4 个构造点。

**Why**：B7/B8 语义事实；`ident` 是模拟引用相等的最小手段；`===` 把结构相等显式化。

| list | 引用（`Array*`） | **身份** | 结构 |

| record | `Comparable.equal`（内容） | 内容 | 结构 |

### 4.3 bug-120（方案 B：解释器协程化，帧上堆）

**前置**：协程设施选型见 §10-2；本方案按"自建轻量 task（复刻 runtime 三条硬经验）"写。

**What**：`Evaluator` 的递归求值改 C++20 协程，递归调用点 `co_await`；协程帧在堆上，**对称转移**使 C++ 栈深恒定。

**Where**：
| 文件 | 改动 |
| :--- | :--- |
| `src/CompileTime/task.h`（新建，~90 行） | 续体 + 对称转移 + 异常穿透 + 同步驱动 `wait()`（设计见下） |
| `src/CompileTime/Evaluator.h:70-95` | **所有直接/间接调用 `evalExpr` 的函数**改 `Task<...>`（不止 7 个：`evalExpr/evalBlock/evalMetaCall/evalCall/evalMethod/evalBinary/evalUnary/evalIndex/evalAssign/evalMember/evalMetaMember/evalRecord/evalList/callFun/callMethod/callBuiltin/callBuiltinMethod/evalCompileError`；**漏一处即编译不过**，无静默风险）(🟡-9) |
| `src/CompileTime/Evaluator.cpp` | `return X;` → `co_return X;`；递归调用 → `co_await …`（约 700–800 行机械转换） |

| `CMakeLists.txt` | 无需新增源文件（`task.h` 是头文件）；C++20 已满足（🟡-3） |

**关键设计点**：
1. **续体 + 对称转移**（复刻 `task.h:285-300` 的写法）：`Awaiter::await_suspend(parent)` 记 `promise.continuation = parent` 并 **`return childHandle`**（对称转移 ⇒ 不增长 C++ 栈）；`final_suspend` 的 `await_suspend` **`return continuation`**（同样对称转移）。
2. **异常穿透**（复刻 `task.h:301-305` 的语义）：`await_resume` **必须** `if (err) std::rethrow_exception(err)`；`wait()` 在 root 级重抛。
3. **同步驱动** `wait()`：`while (!h.done()) h.resume();` —— 由于对称转移，循环里 resume 的始终是"当前最深的未完成协程"（父协程已挂起），栈深恒定。
4. **链深防御（兜底）**：照搬 `task.h:54-55` 的教训——若某编译器实现把对称转移退化为普通调用，返回路径仍会压栈。计划加 `thread_local int g_chainDepth`，`final_awaiter` 递增、`resume` 入口递减；超过阈值（如 1024）直接 `fail("compile-time call depth exceeded")`（或走"队列重驱动"的 trampoline）。用 §7 的深递归用例验证不会触发。
5. **Env 生命周期**：`Env local` 属于协程帧（堆上），`parent=&callerEnv`；调用者帧在 `co_await` 期间存活。
6. **`CallGuard`/`stack_`/`step()`/`chargeMemory`**：位置不变；`CallGuard` 仍为协程体局部 RAII（帧析构时配对弹出）。
7. **`maxCallDepth`**：保持 256；重帧形态可真正到 256 报错。

**代码骨架**（补齐外审 🔴-1 三件套）：
```cpp
// src/CompileTime/task.h
#pragma once
#include <coroutine>
#include <exception>
#include <utility>

namespace aura::ct {
// 编译器内部协程：帧在堆上、对称转移、异常穿透。
// 设计复刻 runtime/task.h:285-308 的三条硬经验（续体 / 对称转移 / await_resume 重抛），
// 但错误载体用 std::exception_ptr（保持 EvalFailure 传播），不引入 GC/Error 依赖（见 plan §2.5）。
template <class T>
struct Task {
    struct promise_type {
        T value{};
        std::exception_ptr err;
        std::coroutine_handle<> continuation = std::noop_coroutine();   // 父协程

        Task get_return_object() {
            return Task{std::coroutine_handle<promise_type>::from_promise(*this)};
        }
        std::suspend_never initial_suspend() noexcept { return {}; }     // eager：进体即跑
        struct FinalAwaiter {
            bool await_ready() noexcept { return false; }
            std::coroutine_handle<> await_suspend(
                std::coroutine_handle<promise_type> h) noexcept {
                return h.promise().continuation;                          // 对称转移回父协程
            }
            void await_resume() noexcept {}
        };
        FinalAwaiter final_suspend() noexcept { return {}; }
        void return_value(T v) { value = std::move(v); }
        void unhandled_exception() { err = std::current_exception(); }
    };

    struct Awaiter {
        std::coroutine_handle<promise_type> h;
        bool await_ready() const noexcept { return !h || h.done(); }
        std::coroutine_handle<> await_suspend(std::coroutine_handle<> parent) noexcept {
            h.promise().continuation = parent;                            // 登记续体
            return h;                                                     // 对称转移到子协程
        }
        T await_resume() {
            if (h.promise().err) std::rethrow_exception(h.promise().err);  // 异常穿透
            return std::move(h.promise().value);
        }
    };

    Awaiter operator co_await() noexcept { return Awaiter{h_}; }
    T wait() {                                                            // 同步驱动
        if (!h_) throw std::runtime_error("empty task");
        while (!h_.done()) h_.resume();
        if (h_.promise().err) std::rethrow_exception(h_.promise().err);
        return std::move(h_.promise().value);
    }
    Task() noexcept = default;
    explicit Task(std::coroutine_handle<promise_type> h) noexcept : h_(h) {}
    Task(Task&& o) noexcept : h_(o.h_) { o.h_ = nullptr; }
    Task& operator=(Task&& o) noexcept { if (h_) h_.destroy(); h_ = o.h_; o.h_ = nullptr; return *this; }
    ~Task() { if (h_) h_.destroy(); }
private:
    std::coroutine_handle<promise_type> h_{};
};
} // namespace aura::ct
```
